Panel

A titled container with an optional disclosure — the gap between cae-card (no header contract, no collapse) and cae-expansion-panel (collapses, but implies an accordion group). The toggle is a real <button> carrying aria-expanded and aria-controls: the WAI-ARIA Disclosure pattern, not Accordion.

1 Example Way, Nowhere. No [toggleable], so there is no toggle and nothing to announce — a plain titled box.

This header is a projected [caePanelHeader], so it can be a real <h4>. The plain [header] string above renders as text — same as p-panel — which is invisible to a screen reader’s heading navigation. Project the slot when the panel is a document section rather than a box.

Fieldset

A real <fieldset> and <legend>, which is why this is a separate component rather than a flag on cae-panel. The part you cannot see: the legend names the group natively. With a screen reader running, move through the fields below — each one is announced as “Billing details, Cardholder name…”. No MatCard and no ARIA attribute reproduces that association.

Edit a field, collapse the group, then expand it again — the values survive. Collapsing sets [hidden] on the content rather than removing it, so the form keeps its values, its scroll position and its pending validation. It also keeps the toggle’s aria-controls pointing at an element that still exists; @if would leave it dangling.
