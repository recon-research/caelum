Alert

The inline status message. Severity is carried by three channels at once — tint, glyph and text — never colour alone (WCAG 1.4.1). The part you cannot see: each alert is a live region, and [politeness] decides whether it interrupts, waits its turn, or stays silent.

@for (item of severities; track item.severity) { {{ item.text }} }

All four are politeness="off" — they are page furniture, present at load, so they announce nothing. The inverse is the rule that matters: never politeness="off" on a message that appears in response to an action. That is WCAG 4.1.3, and it is what the next card demonstrates.

Announcing an alert

A live region announces changes. Press the button with a screen reader running: the danger alert defaults to role="alert", so inserting it interrupts and is read out immediately — the behaviour a failed form submission needs.

Dismissing an alert

A close button destroys the element that holds focus, which would drop a keyboard user to the top of the page (WCAG 2.4.3). [dismissFocusTarget] names where focus goes instead — here, this heading. Close it with the keyboard and the focus ring lands right above.
